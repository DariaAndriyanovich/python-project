# 🧮 Lõpuprojekt – Aritmeetika harjutusprogramm

See on lihtne Pythonis kirjutatud õppimisrakendus, mis aitab harjutada aritmeetilisi tehteid. Programmil on kaks režiimi: harjutus ja test.

## 🎯 Funktsioonid

- Loob juhuslikke tehteid: liitmine, lahutamine, korrutamine, jagamine
- Harjutusrežiim – lõputud ülesanded kuni lõpetamiseni
- Testirežiim – 10 ülesannet, mille järel kuvatakse tulemused
- Kontrollib vastuseid ja annab kohe tagasisidet

## ▶️ Kasutamine

1. Veendu, et Python 3 on paigaldatud  
2. Käivita terminalis:
  ```bash
python lõpuprojekt.py
``` 
3. Järgi programmi juhiseid ja vali soovitud režiim
